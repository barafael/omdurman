# Loading-screen quotes

Curated pool of war-and-peace epigraphs shown on the loading splash.
The game picks one at random each load.

## Format (read by the loader — keep it)

- Each quote is one block separated from the next by a line containing only `---`.
- The quote text is the line beginning with `> `.
- The attribution is the line beginning with `— ` (em dash).
- Anything above the first `---` (this heading and these notes) is ignored.
- Blank lines within a block are fine; edit, reorder, add, or delete blocks freely.
